## Causa técnica revisada

El importador cubano construye los identificadores canónicos de sus clubes con prefijo `CUB-`. El filtro anterior dependía exclusivamente de los campos de país, y el test verifica de forma explícita los clubes cubanos mediante esos identificadores. Para evitar depender de un campo de país ausente o vacío, el filtro actualizado reconoce el prefijo canónico `CUB-` y usa `country_id` / `country_code` como alternativa para registros cubanos sin ese prefijo. El nivel de división usa `division_level` y, si no está definido, `competition_level`.
