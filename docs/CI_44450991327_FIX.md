# Fútbol Nova — corrección de CI 44450991327

**Fecha:** 2026-11-18 (fecha local; registros GitHub en UTC)  
**Motor objetivo:** Godot 4.4.1  
**Plataforma objetivo:** Android ARM64  
**Política:** juego offline; desarrollo y fuentes únicamente mediante GitHub y ChatGPT.

## Diagnóstico confirmado

La ejecución [44450991327](https://github.com/Cumba35/Futbol-Nova/actions/runs/44450991327) terminó en `failure`. Las pruebas de hub/pantallas, vuelo del balón, base 11v11, amistoso con goles y períodos, estructura física de porterías/redes y catálogo/geométrica de estadios terminaron correctamente.

La prueba `tests/test_maximo_padilla_profile.gd` no pudo compilar porque `scripts/legend/legend_career_service.gd:505` hacía referencia directa al identificador global `ManagerCareer`. El test se ejecuta con `godot --headless --script`; en ese modo el singleton de autoload no queda disponible como identificador global para compilar ese script. Después del error, la prueba no pudo instanciar el servicio y agotó su watchdog de 120 segundos.

## Corrección aplicada

Se reemplazó la referencia global por una búsqueda dinámica del autoload:

```gdscript
var manager_career := get_node_or_null("/root/ManagerCareer")
if manager_career == null:
    return {"ok": false, "error": "El servicio ManagerCareer no está disponible en esta ejecución."}
if manager_career.load_career():
    return {"ok": false, "error": "Ya existe una carrera de Manager guardada. Se ha protegido para no sobrescribirla."}
return manager_career.start_coach_career(target_club)
```

Esto conserva el autoload configurado en `project.godot` para el juego normal, evita la dependencia de un identificador global durante la compilación headless y devuelve un error controlado si el servicio no está montado. No modifica las reglas de carrera ni sobrescribe partidas guardadas.
