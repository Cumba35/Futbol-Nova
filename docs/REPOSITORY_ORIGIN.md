# Procedencia y separación de repositorios

- Repositorio independiente: Cumba35/Futbol-Nova.
- Origen de esta copia: Cumba35/Web-Publica-Nova, carpeta futbol-nova/, rama main.
- Repositorio maestro NOVA: Cumba35/Nova-Workspace, carpeta proyectos/juegos/futbol-nova/.
- Política: conservar intacto el proyecto original de Nova Workspace. Esta importación es una copia independiente; no se borra ni se vacía el repositorio público anterior.
- Sincronización futura: cambios entre repositorios se comparan y revisan antes de integrarse. No se permite que la copia independiente sobrescriba automáticamente el proyecto maestro.
- Flujo de trabajo del usuario: ChatGPT + GitHub. Las herramientas de compilación y exportación se ejecutan dentro de GitHub Actions, no se requieren instalaciones locales.
