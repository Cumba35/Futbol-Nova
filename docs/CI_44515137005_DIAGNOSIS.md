# Fútbol Nova — diagnóstico de pausa del balón (CI 44515137005)

**Fecha:** 19-11-2026  
**Motor:** Godot 4.4.1  
**Objetivo:** Android ARM64, partido local/offline.

## Resultado observado

La ejecución [44515137005](https://github.com/Cumba35/Futbol-Nova/actions/runs/44515137005) falló en el paso `Core test — live friendly match, goals and periods`. Las comprobaciones previas de importación, catálogos, controles, GameHub, vuelo del balón y base 11v11 finalizaron correctamente.

El error concreto fue: `El balón se desplazó durante la pausa del partido.` El test configuraba velocidades lineal y angular no nulas inmediatamente antes de pausar el `RigidBody3D`. La implementación congelaba el cuerpo, pero dejaba esas velocidades pendientes durante la transición del estado físico, lo que permitía un posible paso de integración/interpolación.

## Corrección aplicada

En `scripts/gameplay/match_11v11_controller.gd`:

- Se captura también el `global_transform` exacto del balón antes de pausar.
- Se ponen a cero las velocidades lineal y angular antes de activar `freeze`.
- Se restaura el transform capturado y se llama a `reset_physics_interpolation()` para evitar desplazamiento visual de un fotograma.
- Al reanudar, se restaura primero el transform y después el estado original de freeze, las velocidades y el sueño del cuerpo.

No se cambia la física normal durante el juego ni la velocidad que debe recuperar el balón al reanudar.
